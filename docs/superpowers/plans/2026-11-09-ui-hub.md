# UI hub, đợt A: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (mặc định, native) hoặc superpowers:subagent-driven-development để làm kế hoạch này từng task (cách thực thi do 🎯 chọn, xem [agent-routing.md](../../guides/agent-routing.md)). Các bước dùng checkbox (`- [ ]`).

**Goal:** Người chơi bản phát hành đi hết game từ Lobby (màn quán) bằng thanh dưới 6 ô. Nhân vật, Gacha, Bản đồ là panel kín màn; Menu có Ngôn ngữ, Reset dữ liệu (hỏi xác nhận), DEV (chỉ bản dev).

**Architecture:**
- UI thuần: `HubTab`, `HubNavState` (ô hiện tại, Menu, ô chờ mở), `IHubPage`, `MenuViewText`, bảng `UiText.Hub.cs`.
- Restaurant: `IncidentDirector.SetClockPaused` (đồng hồ sự cố dừng khi có panel).
- UI MonoBehaviour: `HubNav` (thanh, panel, Menu, ẩn thanh, ô chờ), `MenuView`. Ba builder cũ dựng panel vào `Restaurant.unity`; `Gacha.unity`, `Characters.unity`, `StageSelect.unity` bị xoá.
- Tám popup con thành trang kín màn cài `IHubPage`; hộp xác nhận và phần thưởng vẽ trên thanh bằng `Canvas` con.

**Tech Stack:** Unity 6000.3.15f1, C#, uGUI `Text` + `Image` (hình có sẵn), Test Framework, CLI `unity`. Không thêm package, không file ảnh.

**Spec:** [docs/superpowers/specs/2026-11-09-ui-hub-design.md](../specs/2026-11-09-ui-hub-design.md) (user duyệt thiết kế, ảnh mô phỏng và bản viết 2026-11-09). "Spec 5.3" dưới đây là mục của spec đó.

## Global Constraints

- Không sửa/xoá tay `.meta`; không đụng `Library/`, `Logs/`, `UserSettings/`, `Temp/`, `Không động tới/`. **Không sửa tay `.unity` hay `.asset`**: scene chỉ đổi bằng builder rồi `Rebuild Restaurant Scene`/`Setup Project`. Xoá scene chỉ qua `AssetDatabase.DeleteAsset` trong `ProjectSetup`.
- **Git: worker không commit, không push** (chỉ 📋 Thư ký). Nhánh `feature/ui-hub` cắt từ `origin/main` mới nhất sau khi nhánh `docs/ui-hub-spec` đã merge (chưa merge thì cắt từ chính nhánh docs đó). Mỗi task kết thúc bằng test xanh và tick checkbox. Không để lẫn: `Assets/_Recovery/`, `Assets/InitTestScene*.unity`, `ProjectSettings/` (trừ `EditorBuildSettings.asset` do `Setup Project` ghi ở Task 3), ảnh chụp.
- **Ảnh mô phỏng đã duyệt:** hub bản 2, trang con bản 1 (spec mục 10). Lệch bố cục so với mô phỏng thì hỏi user, không tự đổi.
- Thanh: `HubNav.BarHeight = 120`; 6 ô theo thứ tự `HubTab` (Restaurant 0, Characters 1, Story 2, Stages 3, Gacha 4, Menu 5); mỗi ô 1/6 bề ngang bằng anchor.
- Tên object **mới** chưa có hình: `<Tên>_PH_<rộng>x<cao>` (spec 5.1–5.6). Object đã có giữ tên cũ (test và `UiDriver` bấm theo tên).
- Quy tắc vạch: trừ nút của thanh, hộp vẽ trên thanh và trang Gacha lúc thanh ẩn, không `Button` nào (kể cả đang tắt, L-025, L-027) giao với dải y 0–120 của khung 1920×1080.
- Reset chỉ chạy sau khi bấm Xoá hết, qua `GameResetter.Reset()` ([D-005](../../decisions/decisions.md)); câu lỗi `hub.reset_failed` không nói "dữ liệu giữ nguyên".
- Chữ người chơi thấy đi qua `UiText` (key `hub.*`, có bản `En`, bảng ở spec 5.11); nhãn builder dựng gắn `LocalizedText` (D-012). `DevOverlay` giữ tiếng Việt.
- Không `[SerializeField]` trong `#if` (lệch bố cục serialize).
- Test: không `[TestCase]` (L-012); tự hỏi "cài đặt sai nào vẫn qua test này" (L-006); test EditMode cần `OnEnable` thì gọi bằng reflection (L-029). Test gọi `ProjectSetup.Run()` hay `*SceneBuilder.Create` thì nạp lại asset bằng `AssetDatabase.LoadAssetAtPath` sau lệnh gọi, kể cả trong `finally` (L-032); sinh scene bằng code thì có test đọc lại tham chiếu từ file (L-002).
- Code theo [code-style.md](../../guides/code-style.md). Sau mỗi task: Console không có lỗi compile hay warning mới; `git status --short` chỉ có file của task.

### Lệnh dùng chung

Kiểm `unity status` **thành một lệnh riêng** trước mọi lệnh batch (L-020). Lệnh batch cần Editor **đóng**; Editor đang mở thì nhờ user đóng, không kill.

```bash
unity test . --mode EditMode --output ../../bdp_BunDauPeo/tests.xml --timeout 600 -- -logFile ../../bdp_BunDauPeo/tests.log
unity test . --mode PlayMode --output ../../bdp_BunDauPeo/playtests.xml --timeout 900 -- -logFile ../../bdp_BunDauPeo/playtests.log
unity run . -- -executeMethod BunDauPeo.EditorTools.ProjectSetup.Run -logFile ../../bdp_BunDauPeo/setup.log
unity run . -- -executeMethod BunDauPeo.EditorTools.ProjectSetup.RebuildRestaurantScene -logFile ../../bdp_BunDauPeo/rebuild.log
```

- Lọc một lớp test: kiểm `unity test -h` trước khi dùng cờ lọc, đừng đoán.
- Đọc `../../bdp_BunDauPeo/tests.xml` (`failed="0"`, `total="N"`), không chỉ dựa vào mã thoát.
- Sau `unity run` kiểm `git status` thấy file đổi rồi mới tin log (L-020). `unity run` bị chặn thì để `ProjectSetupTests` có sẵn gọi `ProjectSetup.Run()` trong lượt EditMode, như phiên Nâng sao A.

Số test: nền **832 EditMode + 16 PlayMode**. Mỗi task ghi số thật vào checkbox cuối. Dự kiến hết kế hoạch **857 EditMode + 20 PlayMode** (Task 1 +8, Task 2 +3, Task 3 +4, Task 5 +5, Task 6 +5; PlayMode Task 4 +3, Task 7 +1).

## Review Focus

1. **Bấm ô khác khi trang của quán đang mở** (Nhân viên, Nâng cấp, Chất lượng): trang phải đóng qua `IHubPage.Close()` và trả `SetSpawnBlocked`, nếu không sự cố không bao giờ sinh lại. Test ở Task 7 (`Hub_TabLoop_OpensEachPanel`, bước mở Nhân viên rồi bấm Gacha).
2. **Đổi ngôn ngữ khi đang ở panel có trang con mở** (ví dụ Chọn đội): sau khi nạp lại, người chơi ở đúng ô với Menu mở; đội đang chọn dở trả về như lúc mở (`Cancel`), không giữ nửa chừng. Test ở Task 4 (`Hub_Menu_Language_KeepsTabAndPersists`, bước mở Chọn đội trước).
3. **Reset khi Menu mở trên panel Gacha hay Nhân vật**: sau Xoá hết, Lobby không panel nào mở, ví và đội như game mới, ô chờ không còn sót. Test ở Task 4 (`Hub_Menu_Reset_CancelKeeps_ConfirmClears`).
4. **Sự cố đang chạy khi mở panel rồi vào trận**: đồng hồ dừng lúc ở panel; vào trận thì sự cố bị huỷ, không tính điểm, và chủ dừng của `HubNav` được trả (`OnDisable`). Test ở Task 2 (`ClockPaused_TwoOwners_AndCancel`, bước `Cancel`).
5. **Bản tiếng Anh dài** ("Restaurant", "Characters", "Reset didn't finish…") tràn ô 320 px hay nút 700 px. Kiểm ở Task 7 (ảnh tiếng Anh); rút gọn trong `UiText.Hub.cs`.
