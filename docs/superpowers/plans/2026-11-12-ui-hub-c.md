# UI hub, đợt C: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (mặc định, native) hoặc superpowers:subagent-driven-development để làm kế hoạch này từng task (cách thực thi do 🎯 chọn, xem [agent-routing.md](../../guides/agent-routing.md)). Các bước dùng checkbox (`- [ ]`).

**Goal:** Màn Tiêu đề (scene riêng), Chọn chế độ trước Bản đồ (Bản đồ có Quay lại), nút Thông báo có chấm và hộp 5 loại việc bấm được tới đích, Hồ sơ (tên sửa được, avatar bằng nhân vật đã có).

**Architecture:**
- UI thuần: `NotifyKind`, `NotifySnapshot`, `NotifyRule`, `WorldFocus`, `TitlePulse`, `PlayerNameRule`, `AvatarRule`; `IHubOverlay` + `HubNav.LayoutPages`; `HubPending` thêm cờ `stageMap`.
- Core/Boot: `PlayerSave.PlayerName`, `PlayerSave.AvatarCharacterId`; `GameSession.SetPlayerName`, `SetAvatar`; `PlayerProfile` (Core, như `RestaurantBarPref`) do `GameBootstrap` đăng ký.
- Scene: `Title.unity` (builder mới, `TitleView`); trong `Restaurant.unity`: `ModeSelectPanel` thay vai panel ô Màn chơi, Bản đồ thành trang con; `NotifyBtn` + `NotifyPopup` + `NotifyView`; `ProfilePopup` + `AvatarView`.

**Tech Stack:** Unity 6000.3.15f1, C#, uGUI `Text` + `Image` + `Button` + `ScrollRect` + `InputField` (hình có sẵn), Test Framework, CLI `unity`. Không thêm package, không file ảnh.

**Spec:** [docs/superpowers/specs/2026-11-12-ui-hub-c-design.md](../specs/2026-11-12-ui-hub-c-design.md) (user duyệt câu hỏi, ảnh mô phỏng bản 1 và bản viết 2026-11-12). "Spec 5.3" dưới đây là mục của spec đó.
