# Online, đợt 3 (liên kết tài khoản, Nhiệm vụ, Hộp thư): Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (mặc định, native) hoặc superpowers:subagent-driven-development để làm kế hoạch này từng task (cách thực thi do 🧭 chọn, xem [agent-routing.md](../../studio/agent-routing.md)). Các bước dùng checkbox (`- [ ]`).

**Goal:** Người chơi liên kết được tài khoản ẩn danh (Google qua Play Games, tên đăng nhập + mật khẩu) và đăng nhập lại từ Tiêu đề; có màn Nhiệm vụ (4 việc ngày + 1 khoá, 9 việc tân thủ) do server trao thưởng; có lượt quay miễn phí mỗi ngày; có Hộp thư với một thư ghim nhắc liên kết; thể lực nhận thêm được vượt trần 100 tới 999.

**Architecture:**
- `BunDauPeo.Rules` thêm `MissionState`, `MissionRules` (chỉ số ngày UTC+7, khung giờ, `View` dùng chung cho máy và server), handler `ClaimMission`/`ClaimAllMissions`/`GachaFreePull`/`DevResetMissions`/`DevAddStamina`, và sửa `StaminaRules` cho vượt trần. Module Cloud Code gọi đúng các hàm đó.
- `IGameServer` thêm 5 lệnh; `PlayerSave` chép `Missions` từ `ServerState`. Thư mục mới `Missions/` (SO `MissionCatalog`, `MissionService`).
- Tài khoản: `IAccountService` (Core) với `LocalAccountService` (test và Editor Local) và `UgsAccountService` (Online). Màn hình mới: `MissionsPage`, `MailPage`, hộp chọn cách / tên + mật khẩu / chuyển tài khoản, hộp xác nhận thể lực; sửa Hồ sơ, Tiêu đề, Gacha, Lobby.

**Tech Stack:** Unity 6000.3.15f1, C#, uGUI (hình có sẵn), Test Framework, CLI `unity`; UGS (package có từ đợt 1); module .NET 8; **plugin Google Play Games (ngoài Package Manager, chỉ thêm khi user cho phép, Task 10)**.

**Spec:** [spec con đợt 3](../specs/2026-11-21-online-3-design.md) (user duyệt 2026-11-21), [spec con đợt 2](../specs/2026-11-16-online-2-design.md), [spec Online](../specs/2026-11-13-online-design.md). "Spec 5.1" là mục của spec con đợt 3; "spec cha" là spec Online. **Kế hoạch:** user duyệt 2026-11-21.

- **Lệnh server lỗi thì không đổi gì trong bộ nhớ;** không `.Result`/`.Wait()`/`Thread` (chạy cả WebGL).

- **Không thêm field cho `PlayerSave` ngoài ba field ở spec 5.2** (`Missions`, `AfkCollected`, `MailRead`).
- **Test không chạm mạng và không chạm save thật:** EditMode, PlayMode dùng `LocalGameServer` + `LocalAccountService`; `dotnet test` dùng kho giả.
- **Tên object mới** (`_PH_<w>x<h>`) đúng spec mục 8; **hình chỉ dùng hình có sẵn của Unity**. Nút tròn Hộp thư: phong thư ghép từ hình vuông + tam giác. Trang mới kín màn (L-033). Không `Button` mới nào giao dải y 0–120 ngoài các hộp vẽ trên thanh dưới (như đợt 2).

- Test: không `[TestCase]` (L-012); "cài đặt sai nào vẫn qua test này" (L-006); RNG có ca giữa chừng; tiền/save có ca "handler ném lỗi" (L-003); PlayMode bấm qua raycast (`UiDriver.Click`, L-036); Setup/Rebuild chạy xong mới chạy test (L-037). Code theo [code-style.md](../../guides/code-style.md).
