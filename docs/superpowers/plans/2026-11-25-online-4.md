# Online, đợt 4 (quà phát từ server trong Hộp thư, hai dòng Thông báo): Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (mặc định, native) hoặc superpowers:subagent-driven-development để làm kế hoạch này từng task (cách thực thi do 🧭 chọn, xem [agent-routing.md](../../studio/agent-routing.md)). Các bước dùng checkbox (`- [ ]`).

**Goal:** User tạo quà trên Unity Dashboard; mọi người chơi trong hạn thấy thư quà trong Hộp thư, nhận đúng một lần (Gem do server trao, Coin/Material máy cộng theo payload); nút Hộp thư có chấm đỏ; Thông báo có dòng "Có quà chưa nhận" và "Có phần thưởng nhiệm vụ chưa nhận".

**Architecture:**
- `BunDauPeo.Rules` thêm `GiftData`, `GiftRules` (kiểm quà, hạn, view), handler `ListGifts`/`ClaimGift`/`ClaimAllGifts`, `ServerState.ClaimedGiftIds`. Module Cloud Code đọc Custom data `gifts` rồi gọi đúng các hàm đó; `LocalGameServer` đọc file `gifts.json`.
- `IGameServer` thêm 3 lệnh. Máy: `GiftService` + `GiftMailSource` vào khung `IMailSource` của đợt 3; `PlayerSave.MailDeleted`; hai `NotifyKind` cuối enum.
- Mọi thứ **chỉ thêm cuối**, không đổi chữ ký của đợt 3: bỏ cả đợt thì đợt 3 chạy y nguyên.

**Tech Stack:** Unity 6000.3.15f1, C#, uGUI (hình có sẵn), Test Framework, CLI `unity`; UGS (Cloud Save Custom data, Cloud Code, có từ đợt 1–2); module .NET 8. **Không thêm package.**

**Spec:** [spec con đợt 4](../specs/2026-11-25-online-4-design.md) (user duyệt 2026-11-25), [spec con đợt 3](../specs/2026-11-21-online-3-design.md), [spec Online](../specs/2026-11-13-online-design.md). "Spec 4.1" là mục của spec con đợt 4. **Kế hoạch:** chờ user duyệt.

## Trước khi bắt đầu (user)

1. Đợt 3 đã merge `main` (PR #23, `fce613b`); nhánh `feature/online-4` cắt từ `main` mới nhất. Thứ tự khoá Unity: sau luồng Nhân vật (cấp nhân vật #1, #2), xem `streams/online.md`. `RewardData`/`CompleteStage` do luồng Nhân vật sửa: **đợt này không đụng**.
2. **Deploy module lên `development`** (Task 3 Step 6) cần user cho phép trong kênh 🔨; bản đợt 3 vẫn chơi được sau deploy (lệnh chỉ thêm).
3. **Tạo Custom data trên Dashboard (development):** id `gifts`, khoá `list`, JSON mẫu ở spec 4.1 (quà thử hạn 7 ngày). Task 3 Step 6 và Task 7 Step 3 cần. Quà thật cho ngày công khai (nội dung, số lượng) **do user quyết**, không nằm trong kế hoạch.
4. Deploy `production` **không** thuộc kế hoạch.

## Global Constraints

- Không sửa/xoá tay `.meta`; không đụng `Library/`, `Logs/`, `UserSettings/`, `Temp/`, `_Scratch/`. **Không sửa tay `.unity` hay `.asset`**: scene chỉ đổi bằng builder trong `ProjectSetup` rồi lệnh Rebuild. Di chuyển file bằng `AssetDatabase.MoveAsset`.
- **Git: worker không commit, không push** (chỉ 📋 Thư ký). Kế hoạch không có bước commit. Không để lẫn `.agents/`, `.vscode/`, `ServerModule/**/bin/`, `ServerModule/**/obj/`, ảnh chụp ngoài `docs/`.
- **Không có khoá bí mật trong repo. Không thêm package.**
- **Server là bản chính:** `Gem` và `ClaimedGiftIds` chỉ đổi khi áp `ServerState` server trả về. Máy **chỉ gửi `giftId`**, không bao giờ gửi số lượng hay tên quà.
- **Lệnh server lỗi thì không đổi gì trong bộ nhớ;** không `.Result`/`.Wait()`/`Thread` (chạy cả WebGL). Từ chối luôn đứng trước bước đổi đầu tiên.
- **D-005:** trường mới (`ServerState.ClaimedGiftIds`, `PlayerSave.MailDeleted`) có giá trị khởi tạo cho game mới, Reset ghi đè bằng bản mặc định; không đổi tên/xoá field cũ. **Không thêm field `PlayerSave` nào ngoài `MailDeleted`.**
- **Không thêm `CommandCode` mới** (dùng `Invalid`, `NotInWindow`, `AlreadyClaimed`, `NothingToClaim`). `ServerProtocol.Version = 3` giữ, `MinProtocolVersion = 2` giữ. Tên lệnh thêm cuối `ServerProtocol`: `ListGifts`, `ClaimGift`, `ClaimAllGifts`.
- **Giờ:** `startUtc <= giờ server < endUtc`; máy hiển thị bằng `ServerTime` (UTC+7), không dùng giờ máy.
- **Giới hạn đọc Dashboard (spec 3.2):** ≤ 200 quà; ≤ 10 dòng thưởng/quà; `amount` 1…1.000.000; `type` ∈ `Gem|Coin|Material`; `id` `[a-z0-9_]` 1…40 ký tự, không trùng; `endUtc > startUtc`. Quà vi phạm bị bỏ riêng quà đó.
- **Test không chạm mạng và không chạm save thật:** EditMode, PlayMode dùng `LocalGameServer`; `dotnet test` dùng kho giả (Custom data giả).
- **Tên object mới** (`_PH_<w>x<h>`) đúng spec mục 6; **hình chỉ dùng hình có sẵn của Unity**. Trang Hộp thư đã kín màn (L-033). Không `Button` mới nào giao dải y 0–120 ngoài các hộp trên thanh dưới.
- **Chữ:** mọi khoá đúng spec 6.2, có bản `En`, trong `UiText.Hub.cs`; không chuỗi tiếng Việt trong code UI. Kiểm bề rộng bản Anh dài nhất (L-039). Tên + thưởng quà lấy từ Dashboard, không qua `UiText`.
- **Ảnh mô phỏng:** spec mục 6 (khung `hub-mailbox-en.png`), user đã duyệt kèm spec; chụp ảnh thật ở Task 7 và so. Lệch bố cục thì hỏi user.
- Test: không `[TestCase]` (L-012); "cài đặt sai nào vẫn qua test này" (L-006); tiền/save có ca "handler ném lỗi" (L-003); PlayMode bấm qua raycast (`UiDriver.Click`, L-036); Setup/Rebuild chạy xong mới chạy test (L-037). Code theo [code-style.md](../../guides/code-style.md).
- Sau mỗi task: Console không lỗi compile hay warning mới; `git status --short` chỉ có file của task.

## Review Focus

Quà là tiền/vật phẩm nên nhận trùng, hạn, mất trả lời là ba chỗ review kỹ nhất.

1. **Nhận hai lần:** `ClaimGift` rồi gửi lại (cùng `requestId` và khác `requestId`) không cộng hai lần; `ClaimAllGifts` ngay sau `ClaimGift` chỉ cộng quà còn lại; hai máy cùng nhận (máy sau `OtherDevice` hoặc `AlreadyClaimed`); Reset rồi nhận lại được (đúng spec 4.2). Test Task 2 (`HandlerGiftTests.Claim_*`), Task 3 (`LocalGameServerTests`).
2. **Mất trả lời `ClaimGift`/`ClaimAllGifts` rồi Thử lại:** Gem một lần; Coin/Material máy cộng **một lần** từ kết quả server đã ghi; kết quả là kết quả server đã ghi. Máy tắt giữa "server ghi" và "máy cộng" chỉ mất Coin/Material (Gem đúng), **giống thưởng màn đợt 2**. Test Task 3 (`Local_LostReply_RetrySameRequest_AppliesOnce`), Task 4 (`GiftServiceTests.Claim_*`).
3. **Hạn:** `startUtc` gồm, `endUtc` không gồm; 1 tick trước/sau mỗi biên; chỉnh giờ máy không nhận được quà hết hạn; quà hết hạn lúc đang mở trang → `NotInWindow`, trang làm mới, toast. Test Task 1 (`GiftRulesTests.Window_*`), Task 2, Task 5.
4. **Dashboard sai tay:** JSON hỏng, id rỗng/trùng/ký tự lạ, `type` lạ, `amount` 0/âm/1.000.001, `endUtc <= startUtc`, 201 quà, 11 dòng thưởng: bỏ riêng quà đó, quà còn lại vẫn nhận; **đọc lỗi trả lỗi server, không trả "rỗng"** để máy giữ thư cũ. Test Task 1 (`GiftRulesTests.Validate_*`), Task 3 (`dotnet test`).
5. **Đợt 3 không vỡ:** `state` đợt 3 thiếu `ClaimedGiftIds` → rỗng, mọi thứ khác không đổi; không có quà → Hộp thư, chấm đỏ, Thông báo y như đợt 3; thư ghim vẫn không bị **Xoá đã đọc** xoá; thư quà chưa nhận không xoá được dù đã đọc; Reset xoá `ClaimedGiftIds` và `MailDeleted`. Test Task 1 (`ServerStateTests.Phase3State_*`), Task 4 (`MailRuleTests.*`).
