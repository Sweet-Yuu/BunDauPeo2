# UI hub, đợt B: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (mặc định, native) hoặc superpowers:subagent-driven-development để làm kế hoạch này từng task (cách thực thi do 🎯 chọn, xem [agent-routing.md](../../guides/agent-routing.md)). Các bước dùng checkbox (`- [ ]`).

**Goal:** Lobby theo ảnh bản 2 của luồng màn (avatar, thanh tài nguyên chung theo màn, thanh chất lượng một hàng, banner Gacha, Shop khoá, thanh quán thu gọn có nhớ, kéo quán), quán vẽ kiểu 2.5D, trang Nhân viên/Nâng cấp làm lại, Lịch sử quay thành hộp, mặc định tiếng Anh.

**Architecture:**
- UI thuần: `ResourceSlots`, `IResourcePage`, `ResourceBarRule`, `WalkPose`, `CustomerBubble`, `TableDishes`; vài hàm chữ mới trong `RestaurantViewText`.
- Core/Boot: `GameLanguage.Resolve(saved)` mặc định En; `PlayerSave.RestaurantBarOpen`; `RestaurantBarPref` (Core, như `LanguageSwitcher`) do `GameBootstrap` đăng ký, `GameSession.SetRestaurantBarOpen`.
- UI MonoBehaviour: `ResourceBarView`, `RestaurantBarView`; `HubNav` thêm `ShowComingSoon`, `OpenPages`, bật/tắt `LobbyHud`. Kéo quán bằng `ScrollRect` có sẵn. 2.5D chỉ đổi `RestaurantSceneBuilder` và phần vẽ người của `RestaurantView`.

**Tech Stack:** Unity 6000.3.15f1, C#, uGUI `Text` + `Image` + `ScrollRect` (hình có sẵn), Test Framework, CLI `unity`. Không thêm package, không file ảnh.

**Spec:** [docs/superpowers/specs/2026-11-11-ui-hub-b-design.md](../specs/2026-11-11-ui-hub-b-design.md) (user duyệt thiết kế, ảnh mô phỏng bản 1 và bản viết 2026-11-11). "Spec 5.3" dưới đây là mục của spec đó.

### Lệnh dùng chung

Kiểm `unity status` **thành một lệnh riêng** trước mọi lệnh batch (L-020). Lệnh batch cần Editor **đóng**; Editor đang mở thì nhờ user đóng, không kill.

```bash
unity test . --mode EditMode --output ../../bdp_BunDauPeo/tests.xml --timeout 600 -- -logFile ../../bdp_BunDauPeo/tests.log
unity test . --mode PlayMode --output ../../bdp_BunDauPeo/playtests.xml --timeout 900 -- -logFile ../../bdp_BunDauPeo/playtests.log
unity run . -- -executeMethod BunDauPeo.EditorTools.ProjectSetup.RebuildRestaurantScene -logFile ../../bdp_BunDauPeo/rebuild.log
```

1. **Kéo bắt đầu ngay trên "!" của sự cố** (nút nằm trong `World`): uGUI chuyển kéo lên `ScrollRect`, nên quán phải dời và sự cố **không** được xử lý. Test ở Task 4 (`Hub_WorldDrag_PansAndClamps_IncidentStillClicks`, bước kéo từ bong bóng).

3. **Màn rộng 20:9** (canvas rộng 2400 đơn vị): vẫn kéo ngang được, HUD neo góc không đè nhau. Test ở Task 4 (`WorldScroll_ClampedNoZoom_WiderThan20by9`, xét `World` rộng ≥ 2400 + 200).
4. **Thể lực đầy:** ô Thể lực không còn dòng "+1 sau", không hiện "+1 sau 0:00". Test ở Task 1 (`StaminaNext_Full_IsEmpty`).
5. **Reset hay đổi ngôn ngữ khi hộp Lịch sử quay đang mở** (đường DEV): hộp phải đóng (L-035), vì nó vẫn là `IHubPage` trong `HubNav._pages`. Test ở Task 6 (`GachaHistory_IsBoxOverBar_AndHubPage`).
