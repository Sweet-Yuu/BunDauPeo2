# Online, đợt 1 (nền): Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (mặc định, native) hoặc superpowers:subagent-driven-development để làm kế hoạch này từng task (cách thực thi do 🎯 chọn, xem [agent-routing.md](../../guides/agent-routing.md)). Các bước dùng checkbox (`- [ ]`).

**Goal:** Mở app phải đăng nhập được (ẩn danh, UGS) mới vào game; save nằm trên server (Cloud Save, khoá `save`); thể lực, AFK, quán chạy theo giờ server; mất mạng thì hộp chặn có Thử lại; Reset xoá cả save trên server, giữ ID; nút Xoá tài khoản; Hồ sơ hiện ID.

**Architecture:**
- `BunDauPeo.Rules` (mới, C# thuần, `noEngineReferences`): giao thức với server (`ServerProtocol`). Module Cloud Code `.ccmr` `BunDauPeoServer` (.NET 8, thư mục `ServerModule/` ngoài `Assets/`) dùng chung file nguồn đó, có hai lệnh `Bootstrap` và `ResetPlayer`.
- Core: `IGameServer`, `OnlineStatus`, `ServerTime`, `LocalGameServer` (server giả cho test và Editor chế độ Local), `CloudSync` (đẩy khoá `save`), `IGameStarter`, `AccountDeleter`; `GameResetter` thành async.
- `BunDauPeo.Online` (mới): `UgsGameServer` (Authentication, Cloud Save, Cloud Code). Boot: `OnlineStartup` dựng session sau khi đăng nhập (thay phần dựng session trong `Awake`). UI: Tiêu đề có bước kết nối, `OnlineOverlay` (hộp mạng, vẽ trên mọi scene), nút Xoá tài khoản, dòng ID.

**Tech Stack:** Unity 6000.3.15f1, C#, uGUI (hình có sẵn), Test Framework, CLI `unity`; UGS: `com.unity.services.core`, `.authentication`, `.cloudsave`, `.cloudcode` (dòng 2.10.x), `.deployment`; .NET 8 SDK cho module.

**Spec:** [docs/superpowers/specs/2026-11-13-online-design.md](../specs/2026-11-13-online-design.md) (user duyệt 2026-11-13). "Spec 5.4" dưới đây là mục của spec đó.

## Review Focus

1. **Mất mạng đúng lúc đang dựng session** (đăng nhập xong, `Bootstrap` lỗi; hoặc `Bootstrap` xong, tải `save` lỗi): Thử lại chạy tiếp từ bước lỗi, không đăng nhập lại thành người chơi mới, không tạo hai session, không cấp đồ game mới lên đè save có sẵn. Test ở Task 5 (`Title_ConnectFailsAtEachStep_RetryEntersOnce`).
2. **Reset khi mất mạng:** không xoá gì (bản đệm, bộ nhớ, server đều giữ), hộp Mất kết nối hiện, Thử lại thì Reset chạy tiếp đúng một lần. Test ở Task 6 (`Reset_ServerFails_KeepsEverything`, `Hub_Reset_Offline_ShowsBoxThenResetsOnce`).
3. **Đẩy `save` đang chạy thì có thay đổi mới, rồi app vào nền:** thay đổi mới không mất (một lượt đẩy nữa, bản cuối trên server là bản mới nhất), không đẩy hai lượt cùng lúc. Test ở Task 3 (`ChangeDuringUpload_UploadsAgain_LatestWins`, `Pause_FlushesPendingChange`).
4. **Chạm Tiêu đề nhiều lần khi đang kết nối, hoặc bấm Thử lại hai lần liền:** chỉ một lần dựng session, `Restaurant` nạp một lần. Test ở Task 5 (đếm `sceneLoaded` và số lần `Bootstrap` của `LocalGameServer`).
5. **Save trên server cũ hơn định dạng hiện tại** (thiếu field mới, như save thử của đợt trước): nạp được, field thiếu lấy mặc định, không cấp lại đồ game mới. Test ở Task 2 (`FromServer_OldJsonMissingFields_LoadsWithDefaults`).
