# Online, đợt 2 (logic server): Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (mặc định, native) hoặc superpowers:subagent-driven-development để làm kế hoạch này từng task (cách thực thi do 🎯 chọn, xem [agent-routing.md](../../guides/agent-routing.md)). Các bước dùng checkbox (`- [ ]`).

**Goal:** Server giữ và tính Gem, nhân vật, mảnh, nâng sao, gacha, thể lực, vào trận và thưởng màn; máy vẫn tính quán, Coin, Material. Mỗi lệnh có màn chờ chặn cả màn, Thử lại không trừ hai lần. Bản đợt 1 bị chặn ở Tiêu đề.

**Architecture:**
- `BunDauPeo.Rules` (C# thuần) có thêm: các kiểu save chuyển từ Core sang (giữ namespace `BunDauPeo.Core`), `ServerState`, `GameData`, `CommandRunner` (bước chung 1–6 ở spec con 6.1) và `ServerHandlers` (từng lệnh). Module Cloud Code gọi đúng các hàm đó, đọc/ghi khoá `state` (Protected), nhúng `GameData.json`.
- Core: `IGameServer` thêm lệnh; `LocalGameServer` chạy `CommandRunner` + `ServerHandlers` trong bộ nhớ; `CommandGate` giữ một lệnh mỗi lúc, mã `RequestId`, hẹn 10 giây, Thử lại; `ServerStateApplier` chép `ServerState` vào `PlayerSave` và bỏ field server giữ khỏi bản tải lên.
- Service (Gacha, Star, Combat, StageProgress, Stamina) đổi hàm ghi sang `async`, gọi server qua `CommandGate`. UI: `WaitOverlay` (mới), hộp Cần cập nhật trong `OnlineOverlay`.

**Tech Stack:** Unity 6000.3.15f1, C#, uGUI (hình có sẵn), Test Framework, CLI `unity`; UGS (package đã có từ đợt 1, không thêm package); module .NET 8 (`Com.Unity.Services.CloudCode.Apis` 0.0.27, `.Core` 0.0.7).

**Kế hoạch:** user duyệt 2026-11-16. **Spec:** [spec con đợt 2](../specs/2026-11-16-online-2-design.md) (user duyệt 2026-11-16) và [spec Online](../specs/2026-11-13-online-design.md). "Spec con 6.1" là mục của spec con; "spec cha 5.7" là của spec Online.
